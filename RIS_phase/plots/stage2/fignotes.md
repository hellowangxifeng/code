# Fig2/3 当前说明

当前主图采用所有方案共同固定接收位置和朝向，且每个功率点重新选择最优宽度。
FOV为半角130 mrad，功率0–100 dBm，Times New Roman 10 pt；黑虚线是精确FOV地板。
画幅严格保留2.67 × 2.37 inch，图例采用10 pt紧凑行距，两图均801 × 711 px（300 dpi）。

| U-RIS* | 零相位RIS。固定接收点偏离原主瓣；采用乐观衍射尾部包络，因此是带星号的参考基准。 |
| ------ | ------------------------------------------------------------ |
| Steer  | 使用全局常相位梯度，使光束指向固定接收机，不额外进行光斑整形或聚焦。 |
| Flat   | 使用平顶光斑候选，根据当前功率下的 ABER 或 OP 选择宽度。     |
| R-BER  | 从全部可行候选中选出 ABER 最小的方案。                       |
| R-OP   | 从全部可行候选中选出 OP 最小的方案。                         |
| Max P  | 选取平均接收功率最大的方案。                                 |

**当前 Fig2/3 的结果在模型逻辑上是合理的，Steering 与 R-BER 接近本身不能说明程序出错。但这意味着在当前固定接收点、80 mm 位置抖动、130 mrad FOV 和可行候选库条件下，Robust 整形对通信可靠性的额外贡献有限。** 若论文重点是证明光斑整形的必要性，还需要结合不同抖动强度及实际光斑形态，说明它在哪些信道条件下能够明显优于 Steering。
