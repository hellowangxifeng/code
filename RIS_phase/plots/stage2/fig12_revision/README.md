# Fig12–14：简短条件说明

- 接收孔径**半径3 cm**；接收高度7.5 m；水下斜程10 m；水入射40°；532 nm；ON功率1 W。
- 水下EGG、大气GG均为**弱湍流**；大气GG形状(17,16)，两者均值归一。
- 每轴位置抖动σ=0–120 mm；角误差每轴σ=25 mrad、偏差(25,0)mrad；FOV**半角240 mrad**。各方案接收端对准自身光斑中心。
- 固定水平板，未输入风浪运动时序；配置中的风速标签不参与这些图，不能用“小风速”解释差距。
- 响应度0.5 A/W，噪声50 μA，OP门限SNR=10。相位库39份；短轴/等效半径≥4 cm、R50≥2 cm、轴比≤1.35。

Fig12(a/b/c)分别为逐σ重选的实际半径、ABER、OP。两族都能调整宽度，使最优风险包络接近。ABER/OP纵轴均为[2e-4,2]，保留低σ底部平台并标出10^0。每幅2.67×2.37 inch，Times New Roman，轴/标签/标题10 pt，图例7.5 pt。

稳定性检查使用8次独立Sobol扰乱、每次32768点，并将孔径积分4×16加密到8×32；对62次比较作保守同时误差控制后，61点方向稳定，**σ=20 mm的ABER微小差异不强行排序**。这些检查针对既有传播场上的接收端数值积分。

控制扫描将FOV缩至60 mrad、角σ增至60 mrad后，共同失收地板使两族更接近。基准下的接近主要来自两族逐点重选；FOV变差时共同地板又会掩盖差别，不能简单归因为环境好。全部扫描仍为弱湍流。

补充Fig13固定σ=80 mm设计的Robust、Max mean，以及固定目标半径10 cm的Flat，再扫描抖动；Fig14在σ=120 mm扫描功率。σ=80 mm时，Robust/固定Flat/Max mean的ABER约0.0299/0.1132/0.2569，差距明显。
