## 1. RIS 器件的基本参数

| 参数                           | 数值及含义                                                   |
| ------------------------------ | ------------------------------------------------------------ |
| RIS 面板                       | **1m×1m**，厚度**1cm**光学玻璃材质，液晶单元排布在玻璃夹层正中间 |
| 液晶单元大小                   | 15mm×15mm，透光区域14.4mm×14.4mm                             |
| 相邻单元之间的距离             | 10mm，此处特指两个器件边缘之间的空隙                         |
| 透射光波长                     | 532 nm                                                       |
| 液晶单元结构                   | 上下层**0.55mm**玻璃基板、上下ITO透明电极、中间**2.5 μm** 的液晶层 |
| 液晶单元数量                   | 40×40=1600                                                   |
| 液晶单元内部相邻电极的中心距离 | **1 μm**，其中电极宽 **0.7 μm**，相邻电极间的空隙 **0.3 μm** |
| 可调相位范围                   | **0-2π rad**                                                 |
| 偏转角参考值                   | **±15.426°**，对应532nm、1μm间隔、空气中的理想采样角度估算   |
| 偏转角控制精度                 | 0.021°                                                       |
| 安装                           | 下层玻璃贴水面放置, 四周设置浮力框架，让框架承担重量。框只负责配重，仿真只考虑1m的玻璃板。 |


**这里要区分两种距离：**

- **10 mm**：两个 15 mm 器件的边缘之间，留下 10 mm 的空隙。
- **25 mm**：从一个器件的中心走到相邻器件的中心，距离是 15 + 10 = **25 mm**。

## 2. 任务目标

RIS_phase原代码是让光尽可能靠近+z方向，现在改成在+z 5m、7.5m、10m的接收平面上，各自寻找偏离板法向尽量小的方向，同时在各自传播距离上获得尽可能优良的接收性能。要在接收平面尽可能汇聚成圆光斑，同时不能聚焦成一个点，必须在接收光功率、光斑宽度、抖动容忍度及通信可靠性之间进行联合优化。

假设接收孔径在光斑范围内瑞利抖动，接收机视场角存在角度误差。将接收机角度误差、有限 FOV 和接收孔径位置抖动（参考4yimiao.pdf）同时纳入OP、ABER计算。分析位置抖动与角度误差对接收功率、ABER 和 OP 的不同影响。

可以用最小化ABER 或OP或最大接收功率为优化目标（允许分别使用 ABER、OP 和接收功率作为主优化目标，但需要比较不同目标产生的 RIS 相位分布、光斑形状和通信性能）。优化光斑的等效半径、光斑中心位置以及能量集中程度。设置明确的最小光斑宽度约束，避免算法将所有光功率集中到单个焦点。分析三个接收距离上光斑尺寸随传播距离的变化。比较普通高斯光斑、圆形光斑整形以及有限宽度平顶光斑等候选方案，判断哪种方案在随机抖动下具有更好的接收性能。比较优化前后的实际可实现相位，而非仅比较无约束理想相位。

给出：1、RIS 下表面入射复光场的振幅与相位表达式。2、RIS 各单元施加相位调制后的出射复光场。3、接收平面任意位置的复电场表达式，考虑传播距离、相位差、倾斜传播和衍射效应。4、根据复电场计算二维光强分布的公式。5、根据接收孔径位置、口径面积和接收角度响应计算瞬时接收功率，进一步对位置抖动、角度误差及其他已建模随机扰动取统计平均，得到平均接收功率、OP、ABER的公式。

优先检查RIS_phase、W_RIS已有的波动传播模型，所有公式需要完整解释变量、物理意义及适用条件。
