# RIS_ML：学习策略，物理算法生成相位

本目录给出面向现有 `RIS_phase` 工程的研究与实施方案。主线是：**机器学习预测状态不确定性和低维调控策略，相位梯度算法生成满足器件约束的实际相位，接收反馈修正模型误差。**

建议方案名称：**有限相位梯度预算下的预测驱动光斑整形与反馈残差补偿**。

| `evidence/design_audit.json` | 参数计算、已有六帧结果摘要、关键源文件指纹；由本次只读核查生成 |

推荐先完成“接收孔径功率评价＋连续曲率分配＋概率位置预测”，再加入反馈补偿。第一阶段使用现有线性／二次相位族，直接接续 `rp_command`、`rp_phase`、`rp_trace` 和 `rp_wave` 的物理模型。

本次交付为设计文档与核查记录，未修改已有 MATLAB 源码，未训练网络或运行大规模仿真。文档中的 `rml_*` 名称均为后续拟新增接口，尚未实现。
