In this folder are reported the tests related to Table 22
NB. For the Free Decay tests without mooring there is only one csv file for the Raw Data as only the motions are captured during this tests.
NB. The trigger Signal is present but it is empty as it was not used during Free-Decay tests. 
NB. In the post processed data the syncronization was done matching the Tension in the mooring system with the kinematic of the floater.

###################################################################################################################################

All data is provided in .csv format. 
The .csv files are organized as follow:

-Data: File Name = 'TestName.csv'.
	-The columns in the csv file represent the following variables: 
		-"Time Surge Sway Heave Roll Pitch Yaw MooringLine1 MooringLine2 MooringLine3 WindForce WaveProbe1 WaveProbe3 WaveProbe4 WaveProbe5 Trigger MarkerError "
